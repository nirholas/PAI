Everything you do before and after you boot PAI

Sign in with an Ethereum or Solana wallet. No email, no password, no tracking beyond your own activity log.

✓

ISO verification

Drop the 8 GB ISO into your browser. It is hashed locally with SHA-256 in a web worker and compared against the GitHub release checksums. The file never leaves your machine.

₿

Bitcoin watchlist

Track up to 20 addresses: confirmed and pending balance plus recent transactions from mempool.space. Watch-only, so no keys are needed.

ɱ

Monero network

Height, hash rate, difficulty and fee per kB from xmrchain, next to live XMR and BTC prices, so you know what the wallets in PAI will see.

◎

Model loadouts

Pick Ollama models, see their real download size from the registry and the estimated RAM they need, and get a ready-to-run ollama pull script for offline use.

⌨

Hardware reports

A shared compatibility list: device, architecture, boot mode, and whether PAI works. Add your own laptop after you boot it.

⚿

API keys

Every dashboard action is also an HTTP endpoint. Create a key and script verifications, watchlists and loadouts from your own tools.

Three steps

Sign in with a wallet

MetaMask, Rabby, Coinbase Wallet, Phantom, Solflare or Backpack. You sign a one-time message; nothing is sent on-chain.

Verify and plan

Hash your download against the release, then build a model loadout that fits your machine's RAM.

Boot and report

Flash the USB, boot offline, then add a hardware report so the next person knows what works.

Same features, over HTTP

Create an API key in the dashboard and call any endpoint with a Bearer token. Public endpoints such as release, market, models and hardware need no key.

  • GET /api/v1/release: latest release and checksums
  • GET /api/v1/market: BTC/XMR prices, fees and network stats
  • GET /api/v1/models/llama3.2:3b: size and RAM estimate
  • POST /api/v1/verify: check a SHA-256 and log it
  • GET /api/v1/btc/address/:addr: address summary
# Check a hash you computed with sha256sum
curl -s https://pai.ninabrekkerese.workers.dev/api/v1/verify \
  -H "Authorization: Bearer $PAI_KEY" \
  -H 'content-type: application/json' \
  -d '{"sha256":"'"$(sha256sum pai-amd64.iso | cut -d' ' -f1)"'"}'

# Which models fit in 8 GB?
curl -s https://pai.ninabrekkerese.workers.dev/api/v1/models/qwen2.5:7b
